# Contributing

Open an issue describing the problem and a small reproduction before proposing
a large change. Keep pull requests focused and add a regression test for bug fixes.

Run `npm test` and `npm run example` with Node.js 20 or newer.
Tests use local servers or injected fetch functions; no external API is required.

Useful next work includes browser integration tests, additional examples, and
feedback from actual applications. Do not add fabricated usage statistics or credits.
